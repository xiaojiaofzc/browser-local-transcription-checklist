# Browser-Local Transcription Page Checklist

A reusable copy and QA checklist for a web page that transcribes a visitor-selected audio or video file in the visitor's browser.

It is designed for product teams that need to describe a browser-local transcription flow without claiming unsupported formats, limits, retention practices, or accuracy figures.

## Included resources

- `browser-local-transcription-checklist.md` — implementation and copy review checklist.
- `claim-inventory.csv` — a compact inventory for recording only claims that a page can substantiate.
- `limit-copy-template.md` — plain-English templates for format, duration, file-size, and processing disclosures.

## Use

1. Start with `claim-inventory.csv` and remove any row your product cannot substantiate.
2. Adapt the checklist and limit copy to the actual browser and model behavior.
3. Test a real local file before publishing the page.

## Live example

ClipText is a browser-local transcript tool that applies this pattern: https://reeltextstudio.com/

## Scope

This repository provides product-copy and QA resources, not an ASR model, model weights, or a guarantee of browser capability.
